Modify the pack

You can modify the current pack through the following git endpoint: {{ git_url }}

All changes will take effect immediately except for config.py (and any dependencies it has) changes, which require DTANM to be restarted to take effect. Any time the pack is updated DTANM will automatically retest the gold program against all attacks and all team programs using the new gold results.

Edit Deadlines

You can update the attack and competition deadline here, these control when submissions for attack and fixes are disabled. Once attack submissions are disabled, the competition enters a grace period that lets teams fix any outstanding attacks without needing to worry about new attacks being submitted. The grace period can be disabled by setting the attack deadline and the competition deadline to the same time.

Dates and times here are in the competition's specified timezone.
